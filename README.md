# Frontend Fundamentals 모의고사

## Getting started

```sh
yarn dev
```

## 추가 개선 사항

- 사용자가 입력한 조건에 맞는 결과가 없는 경우, <적금 상품> 탭에서 "조건에 맞는 상품이 없습니다." 라는 메시지를 보여준다.
- 사용자가 "목표 금액"을 입력하지 않은 경우, <계산 결과> 탭에서 "목표 금액을 입력해주세요." 라는 메시지를 보여준다.
- 사용자가 "월 납입액"을 입력하지 않은 경우, <계산 결과> 탭에서 "월 납입액을 입력하지 않은 경우, 최대 납입 금액을 계산에 적용합니다" 라는 안내 문구를 보여준다.
